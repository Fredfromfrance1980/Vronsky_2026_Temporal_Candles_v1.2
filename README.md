# Vronsky_2026_Temporal_Candles_v1.2
Temporal candles: a calibration map placing tests of general relativity in dimensionless clock coordinates (compactness, acceleration). Recovers the radial acceleration relation of 155 galaxies blindly; wide binaries in Gaia EDR3/DR3 favour GR over MOND. Pre-registered test for Gaia DR4. Paper (EN/FR), code, data.
